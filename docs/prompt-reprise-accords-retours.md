## Rappels de méthode
- Compilation : Linux `taskset -c 0,1`, `-j2` ; Windows `ssh neptune-win` (shell `cmd` : **jamais de `;`** dans une ligne ssh ; envoyer `Cargo.toml Cargo.lock CLAUDE.md crates docs tools tests` par `tar --exclude=target -cf - … | ssh neptune-win 'cd /d C:\Users\lcj\daw-build && tar -xf -'`, puis `call go2.cmd` (tests + CLI + app, journal `all2.log`), et **vérifier la date de `daw-app.exe` et le nombre de binaires verts** comparé à Linux). Le code ASIO/Windows ne se compile pas sous Linux : une erreur n'y apparaît qu'à la compilation Windows.
- Le fil audio n'alloue ni ne bloque jamais (garde-fou `alloc_guard`). Chaque fonction avec ses tests. Aucun essai à l'oreille n'est possible côté Claude : Jean écoute sur la machine Windows ; ne pas relancer l'application pendant son essai sans le prévenir.
- Vérifier la page dans le navigateur intégré (`.claude/launch.json`, port 8791, faux moteur ; `?debug` expose `window.__daw`).
