- 79-90 : partition (module de Scorsaire branché : fenêtre flottante / plein écran / ancrée, boutons de durée, grille d'écriture séparée de la grille d'édition, paroles, voie « Tonalités », blocs par section, vrais triolets) ; courbes de contrôle du piano roll (copier / coller / amincir) ; mélismes (`end` des syllabes).
- 85 : dépôt GitHub privé `LeTournedosRossini/daw-perso`, CI **manuelle** verte sur Linux, Windows, macOS ARM (empreintes de rendu identiques sur ARM).
- 91-93 : **télécommande d'une tablette** par le serveur des retours (droits en bits sur l'adresse : 1 = transport / sections / pré-roll, 2 = régie = mixage de toutes les pistes avec vumètres, 3 = les deux ; 403 sans le droit), **arrêt automatique** (option, désactivée par défaut), **pré-roll à la lecture normale** (la lecture qui suit un déplacement de la tête part du pré-roll avant ; reprise après pause inchangée).
Jean est en train d'**essayer le transport et la régie sur une vraie tablette** (QR d'un retour → choisir les droits → scanner ; pare-feu Windows à accepter pour les réseaux privés). **Attends ses retours** : ils peuvent changer des choses (taille des boutons, appui long de 0,7 s, latence des faders, messages de refus).
